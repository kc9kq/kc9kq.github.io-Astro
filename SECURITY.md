# Security Policy

## Supported versions

Security fixes are provided for the latest deployed version of the site. Older
versions are not supported.

## Reporting a vulnerability

Report suspected vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/kc9kq/kc9kq.github.io-Astro/security/advisories/new).
Do not disclose vulnerabilities in public issues or pull requests.

Please include a description of the issue, its potential impact, and steps to
reproduce it. Avoid accessing or modifying other people's data while testing.
The maintainers will review the report and coordinate any appropriate fix and
disclosure with you.
